# v0.9.7 -- Feature -- universal resume tokens: `csb resume last:3` (grammar unification)

Hand-runnable companion to the migrated `tests/test_resume_set.py` (+ `test_view_index.py`, `test_set_current.py`, `test_epoch_history.py`) -- 1880 automated tests total. Verifies the one-grammar contract on a real machine: the same `view-or-set:N` tokens everywhere, names always winning bare, `--set` as the explicit lane.

**Legend** (for external testers): "token" = `view-or-set:N` (e.g. `last:3`, `boot:2`, `MYSET:3`) -- the roster-row address from `csb set show`; "bare lane" = the token typed as the plain resume query; "explicit lane" = the token after `--set`, which never reads as a session name; "retired forms" = the pre-0.9.7 spellings (`--set 3`, `--set NAME 3`, bare `--set`).

## Prerequisites

- csb 0.9.7+ (`csb -V`).
- At least one epoch with members (`csb set show last`).

## 1. The bare lane (CAUTION: successful commands launch claude)

- [ ] `csb set show last` -> pick a member number N you're willing to actually open.
- [ ] `csb resume last:N` -> launches claude on exactly the session row N showed. Exit it (clean close returns it to reclaimability).
- [ ] `csb resume boot:N` (pick from `csb set show boot`) -> same contract on the boot view.
- [ ] With a named set: `csb resume MYSET:N` -> member N by the set's stored order.

## 2. The explicit lane and the menu

- [ ] `csb resume --set last:N` -> identical result to the bare lane (no shadowing session exists on a normal store).
- [ ] `csb resume --set MYSET` -> the reclaim menu, unchanged: open members hidden, canonical numbers kept, per-row hints now printed as `csb resume --set MYSET:N`.

## 3. Retired forms teach the token (safe -- nothing launches)

- [ ] `csb resume --set 2` -> exit 2; the error names BOTH `last:2` and `boot:2` (the ambiguity that killed the form).
- [ ] `csb resume --set last 2` -> exit 2; hands back `csb resume --set last:2` verbatim.
- [ ] `csb resume --set` (bare) -> exit 2; teaches `--set last:3` and `--set NAME`.
- [ ] `csb resume -h` -> the description shows both lanes and says an exact session name always wins.

## 4. The shadow contract (only if you stage it)

- [ ] Optionally `/rename` a scratch session to literally `last:1`, run `csb backup --no-commit`, then: bare `csb resume last:1` resumes THE SCRATCH SESSION and prints the pointer line naming `csb resume --set last:1`; the flag form addresses roster member 1. Rename the session back afterwards. (Skip freely -- the automated shadow tests cover the mechanics; this is the only way to SEE the disclosure line.)

## 5. Membership verbs share the rule

- [ ] `csb set new SOMETHING boot:1` still echoes the grab (`boot:1 -> <name>`) -- token behavior unchanged there; `csb set rm SOMETHING` cleans up.

## What the mocks don't cover

- A real launch: mocked tests never spawn claude, so section 1 is the only end-to-end proof the resolved UUID reaches `claude --resume`.
- The disclosure line's real-terminal rendering (section 4).
- Muscle memory: whether the retired-form errors actually teach -- if you find yourself typing `--set 2` and the error's suggestion is not instantly pasteable, that is a bug in the message, report it.
